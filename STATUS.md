# SnapGit — статус

На 28 сентября 2026 года:

- Снимки формата 2: ZIP64 + Deflate 9, без внешних Python-зависимостей.
- Вся реализация находится в одном самостоятельном `SnapGit.py`, включая ZIP
  и контроль целостности. Дополнительные модули рядом не требуются.
- SHA-256 каждого файла, ZIP CRC и отдельная SHA-256 всего архива.
- Обязательная полная проверка после записи, перед восстановлением и перед
  решением пропустить неизменившийся проект. Отдельная команда `verify`.
- Публикация только проверенного полного ZIP; ошибки источника/записи/проверки
  не создают готового снимка и не запускают уплотнение.
- Сравнение по содержимому и значимым метаданным; изменения только времени файла
  не создают снимок. При отсутствии изменений уплотнение также пропускается.
- `--keep N` / `-k N` защищает N последних снимков проекта за всё время
  от `-cd` и `-cm`: целое от 1, по умолчанию 1. Для остальных снимков сохраняется
  прежнее уплотнение до одного за день/месяц; итог может быть больше N.
- Явная защита единственного снимка перед `-cd` и `-cm`; если снимков не больше
  `N`, перенос также не выполняется.
- ZIP и контрольная сумма перемещаются в `$purge$` вместе; сохраняемые снимки
  проверяются до переноса старых. Межпроцессная блокировка архива проекта.
- Восстановление extras/full использует только ZIP формата 2. Старые каталоги и
  `--allow-incomplete` больше не поддерживаются.
- Перед изменением целевого проекта снимок проверяется и распаковывается во
  временный каталог; требуется место под его несжатый объём.
- Обычные файлы назначения заменяются через проверенную временную копию.
- Сохраняются Git-состояние, права, символические ссылки, Unicode и Linux-имена
  вне UTF-8 (через отображение технических имён ZIP в манифесте).
- Интеграционные тесты в `test_snapgit.py` проверяют восстановление, пропуск,
  повреждение/обрезку архивов, SHA-256, конкурирующие изменения и уплотнение.

Ограничения: Git index не воссоздаётся; снимок нескольких изменяющихся файлов
не атомарен; для живой SQLite нужна отдельная согласованная копия/остановка записи.

Проверена совместимость ZIP64 на файле 4 GiB + 123 байта: WinRAR 7.23 и
SecureZIP 14.50.1223 успешно проверили архив, включая кириллические имена.

Итоговая проверка: полный набор из 38 тестов прошёл в WSL/Linux. В Windows
прошли 13 проверок глобальной защиты --keep, уплотнения, защиты единственного снимка
и пропуска без изменений. Проверки синтаксиса Python и `git diff --check`
также прошли.

Отдельный тест проверяет backup, verify, пропуск без изменений и restore
при запуске единственного скопированного SnapGit.py из изолированной папки.
